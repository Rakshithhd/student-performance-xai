# Student Performance Prediction with Explainable AI 
## Wep App Features : 
### Input : 
- Attendance %
- Presentation marks
- Assignment marks
- Quiz marks
- Mid Term marks

### Output : 
- Predict the progress to get the best result before Final Exam
- Tell the student which should need to be improve
- Show Percentage of get CGPA 4 or the best cut mark

### Validation : 
- After Final exam,  tell student using the inputed final term answered marks, what will be the grade
